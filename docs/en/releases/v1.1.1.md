# v1.1.1

The About page has a redesigned update card, and upgrades preserve the installation directory.

## Changes

- A separate update card shows the current and latest versions, update status and available actions.
- The installer uses `UsePreviousAppDir` / `UsePreviousGroup` to locate the original installation directory during an upgrade.

## Installation

- Installer (WSLCC-Setup.exe).
- Portable edition (WSLCC-win-x64.zip).
