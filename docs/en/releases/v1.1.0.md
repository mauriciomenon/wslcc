# v1.1.0

This release improves session handling, detects TUN proxies, migrates the Compose directory and introduces localization support.

## Added

- The interface recognizes `E_UNEXPECTED` caused by a proxy in TUN mode and explains the cause.
- Dynamic text uses the generated `AppStrings` catalog and the `L` helper to follow the system language.

## Improvements

- Container operations update individual rows and preserve port information after a restart.
- Compose projects move to `data/compose`. Existing project directories migrate automatically.
- Build, publish and CI steps remove unused language resources.

## Fixes

- After terminating or restarting a session, the app waits for wslc to become ready before refreshing.
- Fixed the initial visibility of the `SkeletonGrid` loading placeholder on empty pages.

## Installation

- Installer (WSLCC-Setup.exe).
- Portable edition (WSLCC-win-x64.zip).
