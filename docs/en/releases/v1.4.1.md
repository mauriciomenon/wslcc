# v1.4.1

Fixed how the app locates `wslc.exe` when WSL is missing from PATH.

## Fixes

- `WslcRunner` previously launched `wslc.exe` by name. If PATH omitted the WSL installation directory, Win32Exception reported file not found (error 2) without recovery instructions. WSL installs to `C:\Program Files\WSL`, but fresh installations, terminals opened before installation and Store/MSIX layouts can leave it out of PATH.
  - Resolve the executable once per process. Check PATH first, followed by known locations including `Program Files\WSL\wslc.exe` and the WindowsApps alias, then try the bare filename.
  - Native error 2 now produces a readable `WslcCliException` listing searched locations and recovery steps. Dashboard guidance recognizes the new message. Settings now directs users to `wsl --update --pre-release` for upgrades and drops the old reference to winget.

## Installation

- Installer (WSLCC-Setup.exe).
- Portable edition (WSLCC-win-x64.zip).
