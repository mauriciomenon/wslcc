# v1.3.0

Added a mini panel for managing containers.

## Added

- Open the 380 x 540 DIP panel from the tray to see container status, start, stop or restart containers in the lower-right corner of the screen.
  - The panel runs in its own lightweight, always-on-top window with a separate lifecycle for frequent access.
  - Only the tray icon toggles the panel. Clicking the taskbar first takes focus from the window, so hiding on focus loss would conflict with the tray click.
  - The window sits in the topmost band immediately below the taskbar, allowing it to slide out from behind the taskbar and remain visible.
  - One persistent worker thread animates each frame with `SetWindowPos`. A generation counter cancels outdated animations, and `SWP_NOZORDER` keeps the stacking order stable to prevent flicker. There is no fade-in on opening.
  - A custom SystemBackdrop sets `IsInputActive=true` so acrylic stays active in the background. Turning off Mica restores a solid background.
  - Each row has start, stop and restart actions, plus an Open button for mapped ports. Statistics refresh every three seconds.
  - A left click on the tray icon toggles the panel by default. The new `app.trayMiniPanel` setting restores the previous action of opening the main window. The tray context menu also has a panel entry. The panel follows theme and material changes.

## Fixes

- Port parsing handles IPv4 and IPv6 bindings. The Open button generates usable URLs and maps `0.0.0.0` and `[::]` to localhost.
- The local `publish.ps1` now passes `-p:PublishTrimmed=false`, matching CI. The Release default, `PublishTrimmed=true`, removed WinRT types and caused a `WinRT.TypeExtensions` null reference during XAML binding at startup. CI already overrode this setting.

## Improvements

- An antialiased vector `Ellipse` replaces the `InfoBadge` status dot and aligns vertically with the container name.
- Mini panel bindings use `Mode=OneWay` to update status text on refresh. A borderless refresh icon rotates while active and prevents overlapping refreshes.
- The close action moved from Session to Startup and tray because it is an app preference. In wslc management, the button now reads Check for WSL updates to distinguish it from application updates on the About page.

## Installation

- Installer (WSLCC-Setup.exe).
- Portable edition (WSLCC-win-x64.zip).
