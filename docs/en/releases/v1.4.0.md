# v1.4.0

Added support for official wslc 2.9.13 features.

## Added

- `WslcCapabilities` parses `wslc --version` and enables each new argument only when the installed version supports it. Version 2.9.12 rejects these options. Older versions use the previous behavior.
- `image list --digests` shows the DIGEST column and JSON digest when supported.
- `pull --all-tags` pulls all tags in a repository when supported.
- `container cp --follow-link` resolves symbolic links when copying on supported versions.
- The `events` command reports container and network lifecycle events and supports `--since`, `--until` and repeated `--filter` options. The new Events page supports bounded history queries, live monitoring and filtering.
- Show the CreatedSince field for images. Hide unsupported controls when wslc is older than 2.9.13.

## Improvements

- Updated `Microsoft.WSL.Containers` from 2.9.12 to 2.9.13 and changed the fetch script's default version to match.

## Fixes

- Without `--until`, `wslc events` streams indefinitely and historical queries never finish. A history query now sets `--until` to the current second plus one because a cutoff at the exact second of an event omits that event.
- Version 2.9.13 enables RedirectionGuard and refuses to traverse reparse points. If `%LOCALAPPDATA%\wslc` is a junction, all wslc operations fail with 0x800701c0. The documented workaround points storagePath to a real directory.

## Installation

- Installer (WSLCC-Setup.exe).
- Portable edition (WSLCC-win-x64.zip).
