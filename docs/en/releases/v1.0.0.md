# v1.0.0

The first stable release of the WSL container desktop manager uses the official wslc CLI to manage images, containers, Compose projects, volumes and logs.

## Added

- List, start, stop, restart and remove containers. View logs and details or open a terminal.
- View and remove images, check pull history and inspect image details.
- Deploy, edit, rebuild, stop and remove Compose projects.
- Manage volumes and networks.
- The system tray icon has a theme-aware menu. Users can configure what happens when they close the window.
- Check for application updates manually or automatically, upgrade through the installer, and install or update wslc.
- Choose an installer or a self-contained portable package.

## Improvements

- `WslcRunner` passes arguments through `ArgumentList` to avoid command injection, uses narrower error detection and terminates child processes on cancellation.
- Compose handles image tags, matches `depends_on` keys, sanitizes project names and inserts or updates deployment records.
- The database uses `busy_timeout`, a snapshot retention policy and write transactions. Removed the unused `WslcApiHost` and `SessionStateRepository`.
- CI reads the version from the tag and produces the ZIP archive and installer.

## Installation

- Installer (WSLCC-Setup.exe).
- Portable edition (WSLCC-win-x64.zip).
