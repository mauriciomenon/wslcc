# v1.8.0

The application now ships in self-contained and framework-dependent editions.

## Added

- Two editions are available.
  - The self-contained edition includes the .NET runtime. It is larger and runs out of the box.
  - The smaller framework-dependent edition requires the .NET 10 Desktop Runtime and Windows App Runtime 2.4 on the system.
- The framework-dependent installer checks for both runtimes before installation. If one is missing, it displays a message and opens the download page.

## Improvements

- The in-app updater downloads the installer for the current edition. Self-contained installations use `WSLCC-Setup.exe`. Framework-dependent installations use `WSLCC-Setup-framework.exe`.
- The `-Framework` switch in `publish.ps1` builds the framework-dependent edition separately.

## Installation

- Self-contained edition (WSLCC-Setup.exe / WSLCC-win-x64.zip).
- Framework-dependent edition (WSLCC-Setup-framework.exe / WSLCC-win-x64-framework.zip).
