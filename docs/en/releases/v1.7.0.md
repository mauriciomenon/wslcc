# v1.7.0

Redesigned Settings and added theme, background and session controls.

## Added

- Settings uses the official Windows Community Toolkit `SettingsControls`. Each `SettingsExpander` groups `SettingsCard` rows in the Windows 11 Settings style.
- Under Appearance, choose a light, dark or system theme and an acrylic, Mica or solid background. Changes apply immediately to the main window and mini panel.
- Start or stop a wslc session from the mini panel or dashboard.
- Start minimized to the tray. Tray switches and drop-down selections save immediately.

## Improvements

- Compose stores files in the configured directory, resolves relative volumes against the Compose file and reuses local images by default. Users can force a fresh pull, follow step-by-step deployment progress, continue in the background or cancel.
- Mini panel improvements include eased animation, drag-to-dismiss, multi-monitor taskbar support, icon buttons and rearranged session controls.
- Error reporting copies diagnostics and opens a prefilled GitHub issue.
- Hiding the app in the tray releases the main window page and trims the working set.

## Fixes

- Changing `Application.Current.RequestedTheme` after startup threw an exception with an empty message. Theme changes now set `RequestedTheme` on the root element.
- Container queries stop when the session stops, preventing an implicit session restart.

## Breaking changes

- Removed the custom accent color setting. Appearance now follows the system accent color.

## Installation

- Installer (WSLCC-Setup.exe).
- Portable edition (WSLCC-win-x64.zip).
