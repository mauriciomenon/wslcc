# v1.2.0

Added support for capabilities introduced in official wslc releases 2.9.8 through 2.9.12.

## Fixes

- Version checks followed the wrong release channel and missed all updates from 2.9.10 onward.
  - The app now checks the releases list. At the time, `/releases/latest` only returned the stable 2.7 series, while wslc shipped as a prerelease.
  - Upgrades now use `wsl --update --pre-release`. The previous winget channel only tracked stable releases.

## Added

- List, create, remove and inspect networks, connect or disconnect containers and prune unused networks from the Networks page.
- Prune unused containers, images, volumes and networks with one click.
- Copy container files using `container cp`.
- Container creation now supports 27 parameters, up from 8, including cpus, memory, hostname, workdir, user, entrypoint, network, stop-timeout, shm-size, tmpfs, gpus, health checks, dns, ulimits and pull policy.
- Added `inspect --size`, `list --size`, `image ls --all` and the log options `tail`, `timestamps`, `details`, `since` and `until`.

## Improvements

- Session settings now take effect. `WslcSettingsFileService` reads and writes all eight fields in the official settings.yaml, preserving comments and formatting. `WslcRunner` passes the global `--session` argument.
- The app checks named sessions before use. If a session is missing, it falls back to the default session to avoid `WSLC_E_SESSION_NOT_FOUND`.
- Updated `Microsoft.WSL.Containers` from 2.9.9 to 2.9.12. The package is available only in GitHub Releases, so builds, publishing and CI now use a local NuGet source and a fetch script.

## Installation

- Installer (WSLCC-Setup.exe).
- Portable edition (WSLCC-win-x64.zip).
