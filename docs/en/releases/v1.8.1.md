# v1.8.1

The app now recognizes error 0x800701c0 when the wslc data directory is a reparse point and explains how to resolve it.

## Changes

- At startup the app checks whether `%LOCALAPPDATA%\wslc` or the default storage path is a reparse point, such as a junction or symbolic link.
- When a startup check detects a reparse point or wslc reports 0x800701c0 (untrusted mount point), the Home page and Containers warning bar explain the recovery options. Choose a real directory for storage or restore `%LOCALAPPDATA%\wslc` to a regular directory.
- Polling for container statistics now logs a repeated error once. Previously, it logged the same error every three seconds.

## Installation

- Self-contained edition (WSLCC-Setup.exe / WSLCC-win-x64.zip).
- Framework-dependent edition (WSLCC-Setup-framework.exe / WSLCC-win-x64-framework.zip).
