# v1.7.1

The tray context menu uses H.NotifyIcon.WinUI for a native WinUI Fluent appearance.

## Changes

- Replaced the WinForms `NotifyIcon` and `ContextMenuStrip`, which used a Win32 appearance and a custom dark palette, with the `H.NotifyIcon.WinUI` `TaskbarIcon` and native `MenuFlyout`. Rendering in `SecondWindow` mode adds rounded corners, materials and theme support.
- Updated to `H.NotifyIcon.WinUI 2.5.0-beta.3`. The updated warm-up measurement prevents clipping on first open, and `ContextMenuThemeMode` supports following the theme.
- Added `TrayMenu.xaml` with a `TaskbarIcon` and `ContextFlyout`, merged in `App.xaml`. The new `TrayIconService` supports `Show`, `ApplyTheme`, `ShowBalloon` and `Dispose`, sets `ContextMenuThemeMode=System`, calls `ForceCreate(false)` and localizes menu items.
- Left-clicking opens the mini panel. Open WSLCC opens the main window. The menu also has a Settings shortcut. `App.ApplyTheme` propagates the theme to the tray.

## Installation

- Installer (WSLCC-Setup.exe).
- Portable edition (WSLCC-win-x64.zip).
