# v1.3.1

Fixed missing localization keys.

## Fixes

- Three `L.Get` calls referenced keys missing from `AppStrings`, which made the UI show the keys themselves. The localization changes in v1.1.0 introduced the issue, which also affected v1.2.0 and v1.3.0.
  - Added Chinese and English translations for `ComposePage.DeployAction`. The main editor button had displayed `ComposePage.DeployAction` instead of Deploy.
  - Added Chinese and English translations for `ComposePage.CancelButton`, the Cancel button in rebuild, stop and delete dialogs.
  - Fixed the incorrect `ContainersPage.DeleteButton` key to use the existing `ContainersPage.DeleteButton.Content`.

## Installation

- Installer (WSLCC-Setup.exe).
- Portable edition (WSLCC-win-x64.zip).
