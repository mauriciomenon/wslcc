# v1.7.2

Added single-instance behavior and a version badge in the title bar.

## Changes

- Windows App SDK `AppInstance` and `FindOrRegisterForKey` enforce a single instance. A second launch redirects activation to the running instance, brings its main window forward and exits. If registration fails, the app starts normally.
- A badge to the right of the title displays the assembly version (Major.Minor.Build).

## Installation

- Installer (WSLCC-Setup.exe).
- Portable edition (WSLCC-win-x64.zip).
