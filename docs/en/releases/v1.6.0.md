# v1.6.0

This release supports official WSL 3.0.1 (wslc GA), adds container icons, redesigns the mini panel and shows Compose deployment progress.

## Added

- The app checks each accessible container URL for a favicon via link rel, common paths and data: URIs. Icons are cached in `%LOCALAPPDATA%\WSLCC\icons` and appear to the left of the Open button, alongside the existing status dot.
- The Compose deployment panel, `OperationProgressPanel`, shows a step counter [i/N], the current phase, scrollable logs and a result summary.
- Container creation supports `--mount`, `--env-file`, `--domainname`, `--network-alias`, `-P` and `--no-healthcheck`.
- Open a session terminal directly from the dashboard's active-session list.
- Each error InfoBar can copy diagnostics (environment, audit and application logs) and open a prefilled GitHub issue with one click.
- Tray switches and drop-down selections now save immediately. An option starts the app minimized to the tray.

## Improvements

- For wslc GA, updated `Microsoft.WSL.Containers` from 2.9.13 to 3.0.1 and switched the update channel from `wsl --update --pre-release` to stable `wsl --update`. The README, Settings, Events and `WslcRunner` now describe the generally available release.
- The mini panel has eased sliding, drag-to-dismiss with springback, multi-monitor taskbar support, progress rings on icon buttons, refresh and session start/stop actions. Controls moved to the top and a descriptive summary replaces Ready at the bottom. The panel and Containers page share `ContainerIconService`, its HttpClient and its cache.
- Compose files now persist in the configured directory. Relative volume mounts resolve against the stored file's directory. Compose reuses a local image with the same name and can force a fresh pull using `--pull always` and a registry mirror. Earlier versions stored files under data beside the executable.
- SVG `<style>` class rules are converted to inline styles so `SvgImageSource` can render icons such as OpenList correctly. Previously they appeared as black squares.
- Removed the main window's Back button, moved the sidebar toggle into the sidebar and aligned the larger logo with the application title.
- Hiding the window in the tray releases the main page content and trims the working set from approximately 180 MB to 40 MB.

## Installation

- Installer (WSLCC-Setup.exe).
- Portable edition (WSLCC-win-x64.zip).
