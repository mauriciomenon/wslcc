# v1.8.0

O aplicativo passou a oferecer uma edicao autocontida e outra dependente do framework.

## Novidades

- Duas edicoes estao disponiveis.
  - A edicao autocontida inclui o runtime do .NET. O pacote e maior e ja vem pronto para uso.
  - A edicao dependente do framework e menor e exige que o .NET 10 Desktop Runtime e o Windows App Runtime 2.4 estejam instalados no sistema.
- O instalador da edicao dependente do framework verifica os dois runtimes antes de instalar. Se faltar algum, exibe uma mensagem e abre a pagina de download.

## Melhorias

- O atualizador interno baixa o instalador da edicao em uso. Instalacoes autocontidas usam `WSLCC-Setup.exe`. Instalacoes dependentes do framework usam `WSLCC-Setup-framework.exe`.
- A opcao `-Framework` do `publish.ps1` gera separadamente a edicao dependente do framework.

## Instalacao

- Edicao autocontida (WSLCC-Setup.exe / WSLCC-win-x64.zip).
- Edicao dependente do framework (WSLCC-Setup-framework.exe / WSLCC-win-x64-framework.zip).
