# v1.8.1

O aplicativo passa a reconhecer o erro 0x800701c0 quando o diretorio de dados do wslc e um ponto de nova analise e orienta a correcao.

## Alteracoes

- Na inicializacao, o aplicativo verifica se `%LOCALAPPDATA%\wslc` ou o caminho de armazenamento padrao e um ponto de nova analise, como uma juncao ou um link simbolico.
- Se a verificacao detectar um ponto de nova analise ou o wslc informar 0x800701c0 (ponto de montagem nao confiavel), a pagina inicial e o aviso da pagina Containers explicam as opcoes de correcao. Escolha um diretorio real para o armazenamento ou restaure `%LOCALAPPDATA%\wslc` como um diretorio comum.
- A coleta de estatisticas dos containers passa a registrar uma unica vez os erros repetidos. Antes, o mesmo erro aparecia no log a cada tres segundos.

## Instalacao

- Edicao autocontida (WSLCC-Setup.exe / WSLCC-win-x64.zip).
- Edicao dependente do framework (WSLCC-Setup-framework.exe / WSLCC-win-x64-framework.zip).
