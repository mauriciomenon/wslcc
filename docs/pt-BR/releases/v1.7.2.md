# v1.7.2

O aplicativo passou a usar uma unica instancia e a exibir a versao na barra de titulo.

## Alteracoes

- O `AppInstance` e o `FindOrRegisterForKey` do Windows App SDK limitam o aplicativo a uma instancia. Uma segunda abertura redireciona a ativacao para a instancia em execucao, traz a janela principal para frente e encerra o segundo processo. Se o registro falhar, o aplicativo inicia normalmente.
- Um selo a direita do titulo exibe a versao do assembly (Major.Minor.Build).

## Instalacao

- Instalador (WSLCC-Setup.exe).
- Edicao portatil (WSLCC-win-x64.zip).
