# v1.1.1

A pagina Sobre ganhou um novo cartao de atualizacao. As atualizacoes preservam o diretorio de instalacao.

## Alteracoes

- Um cartao de atualizacao exibe a versao atual, a mais recente, o estado da atualizacao e as acoes disponiveis.
- O instalador usa `UsePreviousAppDir` / `UsePreviousGroup` para localizar o diretorio de instalacao original ao atualizar.

## Instalacao

- Instalador (WSLCC-Setup.exe).
- Edicao portatil (WSLCC-win-x64.zip).
